# EmpresaSoftware - Sistema de Gestión de Empleados

## 1. Descripción del Proyecto
Sistema desarrollado para optimizar el control de personal mediante Java y una base de datos relacional en MySQL.

## 2. Hipótesis del Proyecto
> "Si se desarrolla un sistema informático para registrar y administrar empleados utilizando Java y MySQL, entonces se facilitará el almacenamiento, la búsqueda, la modificación y la eliminación de los datos, reduciendo el tiempo necesario para gestionar la información y disminuyendo los errores al realizar estos procesos manualmente."

## 3. Tecnologías Utilizadas
* **Lenguaje:** Java (Programación Orientada a Objetos)
* **Base de Datos:** MySQL (Normalización hasta 3FN)
* **Control de Versiones:** Git y GitHub (Flujo basado en ramas y Pull Requests)
